# AI Agent 智能助手（免费版）— 使用手册

> **版本**：v1.0.6-lite | **适用平台**：emlog Pro

---

## 1. 插件简介

AI Agent 智能助手是一款基于 ReAct Agent 的博客智能对话插件。安装后，博客右下角会出现 🤖 按钮，访客和博主可以通过自然语言与 AI 对话，搜索文章、查看分类、了解站点统计等。

### 免费版功能

- 🤖 智能对话（基于大语言模型）
- 🔍 搜索文章、查看分类/标签/统计/评论
- 🧠 AI 记忆（记住用户偏好）
- 💬 前台对话窗口（支持 Markdown）
- 🔒 安全防护（频率限制、内容过滤）

## 2. 安装

### 方式一：后台安装（推荐）

1. 下载 `ai_agent_v1.0.6_lite.zip`
2. 登录 emlog 后台 → **插件** → **插件管理**
3. 点击 **安装插件** → 上传 zip 文件
4. 找到 **AI Agent 智能助手（免费版）** → 点击 **启用**
5. 点击 **设置** 进入配置页面

### 方式二：手动上传

1. 解压 zip，将 `ai_agent` 文件夹上传到 `content/plugins/` 目录
2. 确保路径为：`content/plugins/ai_agent/ai_agent.php`
3. 后台 → 插件管理 → 启用

### 安装后检查

- 前台页面右下角出现 🤖 按钮 ✓
- 后台插件列表显示「AI Agent 智能助手（免费版）」✓

## 3. 基础设置

进入后台 → 插件 → AI Agent 智能助手 → 设置。

### 3.1 配置 LLM（必须）

这是插件工作的前提——需要一个大语言模型 API。

**推荐免费方案**：

| 服务商 | 模型 | 免费额度 | 注册 |
|--------|------|---------|------|
| 硅基流动 | DeepSeek V3 / Qwen3-8B | 送 ¥16 | cloud.siliconflow.cn |
| 智谱 AI | GLM-4 Flash | 永久免费 | bigmodel.cn |
| DeepSeek | DeepSeek V4 Pro | 新用户赠送 | platform.deepseek.com |

**配置步骤**：

1. 注册上述任一服务商，获取 API Key
2. 在插件设置中填写：
   - **接口地址**：服务商提供的 API 地址（如 `https://api.siliconflow.cn/v1/chat/completions`）
   - **API 密钥**：你的 API Key
   - **模型名称**：如 `deepseek-v3` 或 `glm-4-flash`
3. 点击保存

**快速选择**：设置页有预置模型下拉框，选择后自动填充地址和模型名。

### 3.2 其他基础设置

| 设置项 | 推荐值 | 说明 |
|--------|--------|------|
| 温度值 | 0.7 | 越高越有创意，越低越稳定 |
| 最大生成长度 | 2000 | 日常对话够用 |
| Agent 循环 | 开启 | 允许 AI 调用工具 |
| 最大工具轮次 | 3 | AI 单次对话最多调用几轮工具 |
| 访客使用 AI | 禁止 | 建议仅允许登录用户 |

## 4. AI 人格设置

进入 **「AI 人格」** Tab，可以自定义 AI 的角色和风格。

- 内置 4 种快速模板：随笔风、技术文、自媒体风、简约官方风
- 支持自由编辑人格配置
- 点击「重置为默认」可恢复出厂设置

**建议**：根据你的博客定位选择合适的模板，AI 会按照人格配置来回复。

## 5. 前台使用

### 打开对话窗口

1. 访问博客前台（需登录，除非管理员开启了访客权限）
2. 右下角出现 🤖 按钮
3. 点击按钮打开对话窗口

### 基本操作

- **发送消息**：输入内容 → 回车或点击「发送」
- **新建对话**：点击标题栏「+」按钮
- **关闭窗口**：点击「×」按钮

### 常用指令示例

```
我的博客有哪些分类？
帮我找一下关于 Docker 的文章
最近发布了哪些文章？
我的博客有多少篇文章？
介绍一下你自己
```

## 6. 常见问题

### Q1: 看不到 🤖 按钮

- 检查插件是否已启用
- 检查访客权限设置（未登录时可能被隐藏）
- 强制刷新页面（Ctrl+F5）

### Q2: AI 不回复

- 检查 LLM API 配置是否正确
- 检查 API Key 是否有效、余额是否充足
- 检查服务器能否访问外网

### Q3: 回复很慢

- 正常响应时间 3~15 秒
- 超过 30 秒可能是 API 服务商响应慢
- 可以尝试更换其他服务商

### Q4: 如何备份配置

点击设置页顶部的「导出设置」按钮，下载 JSON 配置文件。导入时选择该文件即可恢复。
