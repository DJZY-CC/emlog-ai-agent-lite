## 一、产品定位

基于 **ReAct Agent 模式**的 emlog 博客智能运维插件。通过大语言模型（LLM）+ Function Calling 工具调用 + 三层记忆系统，让 AI 真正读懂博客并执行内容管理操作。

## 二、v1.0.6 更新内容

### 2.1 配图三种模式

| 模式 | 说明 |
|------|------|
| generate | 纯文生图，仅使用 AI 生成图片 |
| generate_then_search | 文生图优先，失败后自动搜索网络图片 |
| search | 纯搜索，直接从网络搜索图片 |

### 2.2 多源图片搜索

| 平台 | 免费额度 | API Key 配置字段 |
|------|---------|-----------------|
| Pexels | 每月 20,000 次 | img_search_api_key |
| Unsplash | 每小时 5,000 次 | img_search_unsplash_key |
| Pixabay | 每分钟 100 次 | img_search_pixabay_key |

支持多源降级：配置多个 API Key 后，搜索时按顺序自动尝试。

### 2.3 对话历史污染修复

- LLM 返回错误时，不再存入对话历史（防止模型从历史中学习错误回复模式）
- LLM 返回错误时，不再写入用户记忆（防止错误文本被注入系统提示词）

### 2.4 新增工具

| 工具 | 功能 | 权限 |
|------|------|------|
| search_images | 从 Pexels/Unsplash/Pixabay 搜索网络图片 | 角色控制 |

### 2.5 配置导出导入

新增字段自动支持：
- img_mode（配图模式）
- img_search_provider（搜索源）
- img_search_api_key / img_search_unsplash_key / img_search_pixabay_key
- 导出时脱敏，导入时跳过 *** 标记
