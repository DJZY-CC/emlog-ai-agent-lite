# AI Agent 智能助手（免费版）

> emlog 博客平台基于 **ReAct Agent** 的智能对话助手

## 功能

- **ReAct Agent 引擎** — 多轮工具调用，自动推理
- **7 个只读工具** — 搜索文章、查看分类/标签/统计/评论
- **三层记忆系统** — AI 人格 + 用户记忆 + 站点上下文
- **前台对话窗口** — Markdown 渲染、响应式、PJAX 兼容
- **安全防护** — 频率限制、内容过滤
- **配置导入导出** — 一键备份恢复

## 安装

1. 下载 `ai_agent.zip`
2. emlog 后台 → 插件管理 → 安装插件 → 上传
3. 启用 → 设置 → 配置 LLM API（推荐 DeepSeek V4 Pro）

## 环境要求

- emlog Pro 2.x / PHP 7.4+ / MySQL 5.6+
- PHP 扩展：cURL、JSON、PDO
