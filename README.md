# AI Agent 智能助手（免费版）

> emlog 博客平台基于 **ReAct Agent** 的智能对话助手 — 让 AI 读懂你的博客

## 免费版功能

- 🤖 ReAct Agent 引擎（多轮工具调用）
- 🔍 7 个只读工具（搜索/查看/统计/评论）
- 🧠 三层记忆系统
- 💬 前台对话窗口（Markdown渲染、响应式）
- 🔒 安全防护（频率限制、内容过滤）
- ⚙️ 完整后台设置

## 安装

1. [下载最新 Release](https://github.com/DJZY-CC/emlog-ai-agent-lite/releases)
2. emlog 后台 → 插件管理 → 安装插件 → 上传 zip
3. 启用 → 设置 → 配置 LLM API
