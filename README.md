# AI Agent 智能助手（免费版）

> emlog 博客平台基于 **ReAct Agent** 的智能对话助手 — 让 AI 读懂你的博客

## 免费版功能

- 🤖 **ReAct Agent 引擎** — 多轮工具调用，自动推理决策
- 🔍 **7 个只读工具** — 搜索文章、查看分类/标签/统计/评论
- 🧠 **三层记忆系统** — AI 人格 + 用户记忆 + 站点上下文
- 💬 **前台对话窗口** — Markdown 渲染、响应式设计、PJAX 兼容
- 🔒 **安全防护** — 频率限制、内容安全过滤
- ⚙️ **完整后台设置** — 7 个配置 Tab
- 📦 **配置导入导出** — 一键备份恢复

## 快速开始

```bash
# 1. 下载
https://github.com/DJZY-CC/emlog-ai-agent-lite/releases

# 2. 安装
emlog后台 → 插件管理 → 安装插件 → 上传zip → 启用

# 3. 配置LLM
设置 → 填写API地址+密钥+模型名 → 保存

# 4. 使用
前台右下角点击 🤖 → 开始对话
```
